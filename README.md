# COMP110 Fall 2026 Student Workspace

Welcome! This repository is the starting point for your COMP110 Fall 2026
student workspace. It contains the course projects and supporting files you need.

To get started:

- Open [`workspace.code-workspace`](workspace.code-workspace) in Visual Studio
  Code. This loads the complete course workspace; do not open just one of its
  project folders.
- Go to the [`support` setup instructions](support/README.md).
- Follow the guide for your operating system and complete the workspace setup.

If you return to the workspace later and need to check or update its projects,
the `support` instructions also explain how to run the workspace sync task.
